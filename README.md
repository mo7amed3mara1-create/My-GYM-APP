# MY GYM - تطبيق إدارة الصالة الرياضية بدون إنترنت (100% Offline)

تطبيق متكامل واحترافي لإدارة الصالات الرياضية مخصص لمالك الجيم (الكابتن). يعمل التطبيق بالكامل **محلياً وبدون اتصال بالإنترنت (Offline-First)**، دون الحاجة إلى خادم (Server) أو واجهة خلفية، مع الحفاظ على سرعة فائقة في الأداء، وتصميم احترافي يتبع نظام التصميم الصناعي الحديث (Industrial Dashboard).

---

## المميزات الرئيسية

1. **اسم وشعار التطبيق (MY GYM)**:
   - الاسم المعتمد: **MY GYM** في كامل شاشات وترويسات التطبيق.
   - الشعار البرمجي: شعار متجهي هندسي مرسوم برمجياً بالكامل (`CustomPaint`) بدون أي ملفات صور خارجية، متجاوب وعالي الدقة.
   - ألوان الهوية: أحمر قرمزي عميق (`#C8102E`)، خلفية لافندر فائقة النعومة (`#F8F7FF`)، وبطاقات بيضاء ناصعة مستديرة 18-20 بكسل.

2. **تسجيل دخول فوري للمالك (Instant Auto-Onboarding)**:
   - يعمل فوراً بدون تعقيد؛ عند أول تشغيل يتم تسجيل واعتماد اسم المستخدم وكلمة المرور المكتوبة فوراً والدخول مباشرة للوحة التحكم.
   - تشفير كلمات المرور بحماية `SHA-256` مع `Salt` عشوائي.
   - خيار إضافي بالأسفل لإعادة تعيين الحساب عند نسيان البيانات دون فقدان أي عضو أو اشتراك.

3. **لوحة التحكم الرئيسية (Dashboard)**:
   - تحية ديناميكية للكابتن ومؤشر مباشر (Live).
   - شبكة بطاقات 2×2: الأعضاء النشطون، ينتهي قريباً، منتهي الصلاحية، وحضور اليوم.
   - بطاقة الإيرادات المالية للشهر الحالي مع شريط بياني للمقارنة وقيم (المحصل، المتوقع، والمتأخرات).

4. **إدارة المشتركين والاشتراكات**:
   - توليد رقم عضوي فريد تلقائياً (4 أرقام 1000–9999) دائم ولا يتكرر.
   - حساب تواريخ نهاية الشهور والسنوات الكبيسة بدقة تقويمية.
   - بحث سريع وفلاتر (الكل، نشط، ينتهي، منتهي، غير مسدد).
   - زر تبديل سريع لـ (مدفوع ✅ / غير مسدد ❌) في بطاقة العضو مع التراجع (Undo).

5. **تسجيل الحضور الفوري (Fast Check-in)**:
   - إدخال فوري وسريع للأرقام الأربعة لخدمة طابور الجيم بسرعة.
   - بطاقة نتائج فورية بألوان الحالات (أخضر، كهرماني، أحمر) مع منع التكرار في نفس اليوم.

6. **نظام التنبيهات ورسائل الواتساب الديناميكية**:
   - رسائل واتساب ذكية تفتح محادثة المشترك برقم دولي مصري تلقائياً (`01xxxxxxxxx` إلى `201xxxxxxxxx`) مع تعبئة المتغيرات (`{name}`، `{end_date}`، `{days_left}`، `{amount}`، `{gym}`).
   - متابعة المشتركين الغائبين والمقترب انتهاؤهم والمنتهين مع زر تجديد فوري.

7. **النسخ الاحتياطي والأمان**:
   - تصدير كامل لقاعدة البيانات بصيغة `JSON` وتصدير الأعضاء بصيغة `CSV` للإكسيل.
   - استعادة كاملة وآمنة مع التحقق الأمني.
   - نقطة توسع معمارية لـ QR Code للمرحلة الثانية.
